# OSCURA: The Second Shadow

**Oscura: The Second Shadow** is an atmospheric puzzle-platformer where you control two entities simultaneously: the physical **Heroine** and her spectral **Shadow**. 

Explore a dark, decaying world filled with ancient clockwork machinery, ethereal hazards, and ominous void creatures. Master the unique **Shadow Separation** mechanic to solve puzzles, traverse impossible gaps, and survive the encroaching darkness.

## 🎮 Key Features

*   **Dual-Character Gameplay**: Control the Heroine and her Shadow independently. Separate them to scout ahead, trigger switches, or phase through walls.
*   **Shadow Mechanic**:
    *   **Separate**: Detach your shadow to explore freely (flight, invulnerability to physical traps).
    *   **Recall**: Snap your shadow back to you instantly.
    *   **Teleport**: Swap places with your shadow to cross vast distances.
*   **10 Distinct Levels**: Journey through 5 unique biomes, from the amber-lit *Dark Prison* to the monochrome *Abyssal Depth*.
*   **Atmospheric Visuals**: A striking art style with dynamic lighting, particle effects, and color-coded level themes.
*   **Challenging Hazards**: Dodge falling rocks, spinning blades, and ethereal walls that only one form can pass.

## 🕹️ Controls

| Action | Key |
| :--- | :--- |
| **Move** | `Arrow Keys` / `WASD` |
| **Jump** | `Up Arrow` / `W` |
| **Separate / Recall Shadow** | `Spacebar` |
| **Move Shadow** | `Arrow Keys` (When separated) |

## 🛠️ Installation & Setup

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/RaviDandaiya/Dark-Shadow-adventure-game.git
    cd Dark-Shadow-adventure-game
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Run Development Server:**
    ```bash
    npm run dev
    ```
    Open your browser to `http://localhost:5173` (or the port shown in terminal).

4.  **Build for Production:**
    ```bash
    npm run build
    ```

## 🏗️ Technologies Used

*   **Phaser 3**: Robust 2D game framework.
*   **TypeScript**: For type-safe, maintainable code.
*   **Vite**: Fast build tool and development server.

## 🎨 Level Themes

The game features distinct visual styles that evolve as you progress:
*   **Lvl 1-2**: *The Dark Prison* (Amber)
*   **Lvl 3-4**: *The Ethereal Void* (Cyan)
*   **Lvl 5-6**: *The Blood Foundries* (Crimson)
*   **Lvl 7-8**: *The Toxic Sewers* (Green)
*   **Lvl 9-10**: *The Abyssal Depth* (Monochrome)
